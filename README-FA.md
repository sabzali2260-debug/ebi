# ZEBEL RADIO 1.4.1 — نسخهٔ تک‌صفحه‌ای مخصوص اندروید

- نمایشگر دیجیتال تمام‌صفحه و هدر با لوگوی اصلی ارسالی.
- چرخ قرقره‌ای پنج‌موقعیتی در همان صفحه؛ با کشیدن یا اسکرول ایستگاه عوض می‌شود.
- نام ایستگاه و کشور در ردیف انتخابی؛ قلب برای ذخیرهٔ علاقه‌مندی.
- دکمه‌های قبلی، پخش، بعدی و Mute در یک ردیف.
- ولوم خطی عمودی کنار قرقره.
- منوی پایین، مینی‌پلیر، پلیر دوم، نوار ایستگاه و پیچ‌های گرد از نمای اصلی حذف/پنهان شده‌اند.
- Amp Tone فقط در تنظیمات صدا.
- انتخاب تصویر پس‌زمینه از گالری، اعمال فوری و ذخیرهٔ محلی.
- آیکن نصب از نشان اصلی کاربر استفاده می‌کند.
