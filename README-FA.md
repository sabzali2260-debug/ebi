# ZEBEL RADIO — Android 1.1

این شاخه سورس اپلیکیشن اندروید تمام‌صفحه و مخصوص گوشی است.

## قابلیت‌های نسخه 1.1
- نمایشگر بزرگ عمودی با ساعت و تاریخ میلادی.
- نوار متحرک واضح شامل نام ایستگاه و کشور.
- فهرست ایستگاه‌ها به‌صورت کشویی؛ با انتخاب ایستگاه دوباره جمع می‌شود.
- بهبود اکولایزر با رسم سبک‌تر، نرخ پاسخ وابسته به فریم و رسم فقط نمایشگر قابل‌مشاهده در موبایل.
- پروفایل پاسخ سریع / متعادل / استودیویی، پیش‌تنظیم‌های بیشتر EQ و تقویت هوشمند بلندی صدا.
- شش پس‌زمینهٔ آماده و انتخاب تصویر از گالری گوشی.
- ذخیرهٔ کاتالوگ ایستگاه‌ها برای شروع سریع و حالت آفلاین.
- تازه‌سازی خودکار هر شش ساعت و هنگام بازگشت به برنامه؛ لینک‌های ایستگاه‌های علاقه‌مندی و اخیراً نیز از Radio Browser دوباره بررسی می‌شوند.
- آیکن لانچر بر اساس نشان اصلی ارسالی کاربر.
