# ZEBEL RADIO — اپلیکیشن تمام‌صفحه اندروید

این شاخه سورس اپلیکیشن Android است. نسخهٔ موبایل ZEBEL RADIO داخل اپ بومی WebView جاسازی شده و در حالت immersive اجرا می‌شود.

## امکانات
- نمایش تمام‌صفحه؛ نوار وضعیت و ناوبری در حالت immersive پنهان می‌شوند.
- صفحهٔ عمودی اختصاصی گوشی: نمایشگر و کلیدهای قبلی/پخش/بعدی در بالا، ولوم و تیونینگ در یک ردیف و فهرست ایستگاه‌ها پایین‌تر.
- لوگوی اصلی و رابط گرافیکی از فایل HTML نهایی حفظ شده‌اند.
- سرویس foreground و اعلان برای پخش رادیو.
- حداقل Android 6 / API 23؛ هدف API 35؛ شناسه بسته com.zebel.radio.

## دریافت APK
GitHub Actions با هر push به شاخهٔ zebel-radio-android برنامه را کامپایل و APK debug را به شکل Artifact با نام ZEBEL-RADIO-APK بارگذاری می‌کند. از تب Actions آخرین اجرای موفق را باز کنید و Artifact را دانلود کنید؛ داخل ZIP فایل app-debug.apk قرار دارد.

APK debug برای نصب شخصی مناسب است. انتشار عمومی در فروشگاه نیازمند کلید امضای release اختصاصی است.
