# ZEBEL RADIO 1.3 — نسخهٔ تک‌صفحه‌ای اندروید

این نسخه برای گوشی به‌صورت تمام‌صفحه طراحی شده است.

## تغییرات نسخه 1.3
- لوگوی اصلی ارسالی در سربرگ بزرگ و در آیکن لانچر برنامه استفاده شده است.
- نمایشگر دیجیتال بزرگ با ساعت و تاریخ میلادی.
- نوار متحرک فقط نام ایستگاه و کشور را نشان می‌دهد.
- انتخاب‌گر چرخشی ایستگاه‌ها در همان صفحه با تب‌های همه، علاقه‌مندی و اخیراً و قلب ذخیره.
- کلیدهای قبلی، پخش، بعدی و Mute در یک ردیف.
- کنترل خطی صدا کنار چرخ ایستگاه.
- پنل دوم پخش و فهرست تکراری پایین صفحه حذف شده‌اند.
- Amp Tone در تنظیمات صدا قرار دارد.
- اکولایزر سبک‌تر، تنظیم پس‌زمینه و انتخاب عکس از گالری.
- تازه‌سازی فهرست و لینک ایستگاه‌ها از Radio Browser.

شناسه نصب: `com.zebel.radio.v13`
نسخه: `1.3.0` — حداقل Android 6 / API 23.
این نسخه کنار نسخه‌های قبلی قابل نصب است و تنظیمات نصب قبلی را حذف نمی‌کند.
