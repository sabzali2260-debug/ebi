# سپر | SEPAR

نسخهٔ آزمایشی اندروید برای بررسی رابط فارسی، اعلان تمام‌صفحه، سرویس پیش‌زمینه، آژیر سیستمی و پیام گفتاری فارسی.

## ساخت APK

این پروژه با Android Gradle Plugin 8.10.1، Gradle 8.11.1، JDK 17 و Android SDK 36 ساخته می‌شود.

```bash
gradle --no-daemon :app:assembleDebug
```

فایل خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## محدودیت‌های مهم ایمنی

این نسخه به هیچ منبع رسمی یا سامانهٔ هشدار عمومی ایران متصل نیست و هشدار واقعی دریافت یا اعتبارسنجی نمی‌کند. دکمهٔ صفحه فقط صدای آزمایشی را اجرا می‌کند. انتخاب جنسیت گوینده در این نسخه فقط در متن آزمایشی منعکس می‌شود و تضمین نمی‌کند موتور گفتار دستگاه صدای مرد یا زن ارائه کند. پوشش پس‌زمینه و صفحهٔ قفل نیز باید روی دستگاه‌های واقعی و با مجوز اعلان/نمایش تمام‌صفحه آزموده شود.

تا زمان اتصال و ممیزی منبع رسمی هشدار و آزمون میدانی، این برنامه را ابزار ایمنی یا جایگزین اعلان‌های رسمی تلقی نکنید.
