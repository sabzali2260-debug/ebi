# سپر | SEPAR — Android 0.3.0

نسخهٔ ارتقایافتهٔ آزمایشی برای اندروید ۱۲ تا ۱۶.

## قابلیت‌های پیاده‌سازی‌شده
- آژیر پیوستهٔ رفت‌وبرگشتی با PCM stream (دیگر بوق کوتاه ToneGenerator نیست).
- سه سطح محلی: اطلاع‌رسانی، هشدار و اضطراری.
- سطح ۲ و ۳: آژیر پیوسته، لرزش و صفحهٔ هشدار قرمز چشمک‌زن در صورت مجاز بودن نمایش تمام‌صفحه.
- اعلان foreground با دکمهٔ توقف و WakeLock محدود.
- انتخاب صدای فارسی برای دو پروفایل زنانه/مردانه از بین صداهای فارسی نصب‌شده در موتور TTS دستگاه؛ کاربر باید نمونه‌ها را گوش کند و به هر پروفایل نسبت دهد.
- نقشهٔ آنلاین ایران با نشانگر شهرهای اصلی و صفحهٔ مرجع ثانویهٔ مناطق NOTAM.
- پیوند مستقیم به Iran AIM، EASA و Flightradar24 برای بررسی دستی.

## ساخت APK

نیازمندی‌ها: JDK 17، Android SDK 36، Gradle 8.11.1.

```bash
gradle --no-daemon -p separ-app :app:assembleDebug
```

خروجی:
`separ-app/app/build/outputs/apk/debug/app-debug.apk`

## منابع هوانوردی و محدودیت‌های ایمنی

- **Iran AIM** مرجع رسمی اطلاعات هوانوردی/NOTAM برای Tehran FIR است: https://ais.airport.ir
- **EASA CZIB** یک بولتن ارزیابی ریسک برای اپراتورهای مشمول مقررات EASA است؛ به‌تنهایی دستور عمومی «بسته‌شدن کل آسمان ایران» نیست.
- **Flightradar24** در این برنامه فقط لینک مشاهدهٔ دستی دارد. شرایط API استفاده از دادهٔ آن در تصمیم‌های ایمنی/پروازی را منع می‌کند و دسترسی برنامه‌ای به وب‌سایت به‌جز API را scraping ممنوع کرده است.
- صفحهٔ OIBK صرفاً یک نقشهٔ ثانویه/تجمیعی برای بررسی است، نه مرجع رسمی. مرز FIR نمایش‌داده‌شده در آن تقریبی است.
- نسخهٔ حاضر هنوز به فهرست رسمی و machine-readable NOTAM از Iran AIM متصل نشده و هشدار خودکار بسته‌شدن آسمان تولید نمی‌کند. از کاهش پروازهای دیده‌شده در ADS-B نیز هیچ‌گاه بسته‌بودن حریم هوایی استنتاج نمی‌شود.
- آزمون دکمه‌های سطح هشدار، هشدار واقعی را شبیه‌سازی نمی‌کند. اجرای صفحهٔ تمام‌صفحه روی صفحهٔ قفل به مجوز Notification/Full-screen intent، سازندهٔ دستگاه و تنظیمات کاربر وابسته است.
- در صورتی که موتور TTS دستگاه صدای فارسی نداشته باشد، برنامه گفتار فارسی را تولید نمی‌کند؛ دو پروفایل باید از میان صداهای واقعی نصب‌شده انتخاب شوند.
- نقشهٔ پایه به اینترنت نیاز دارد؛ نقشهٔ آفلاین و لایه‌های قانونی/دقیق مختصات NOTAM هنوز در این نسخه فراهم نیستند.

این برنامه ابزار کمکی آزمایشی است و جایگزین هشدارهای رسمی عمومی، دستورهای اضطراری، NOTAM/AIP یا خدمات ایمنی دولتی نیست.
